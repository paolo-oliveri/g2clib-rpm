Git repository to build rpm for g2clib with tagged version for [GrADS](https://github.com/paolo-oliveri/GrADS).

The g2clib package is included as a submodule with latest tested tag.

Please use RPM tools to build and install the package for RHEL Linux Distributions.

NOTE: for newer fedora 43 the g2clib package versioned 2.2.0 have the shared libraries too, so this package is not mandatory anymore to build GrADS.
